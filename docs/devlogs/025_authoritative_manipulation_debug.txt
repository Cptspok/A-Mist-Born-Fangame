Actual changes relative to 024
- APPROACH now commands (reference_position - actual_COM) / physics_step.
  Removed incremental reference displacement plus bounded gradual recovery.
  The next unblocked native step therefore targets the reference itself, not
  a lagged recovery point. Native damping/gravity preparation remains separate.
  No force tuning, radius tuning, hold-point movement or spring tuning.
- Collision tests constrain only the next commanded step. The approach clock
  pauses while blocked, avoiding accumulated trajectory catch-up against a wall.
  Reference/hold destination is never collapsed by sweep travel. Separating
  floor contacts allow lift; native collisions/CCD remain enabled.
- HOLD convergence now checks observed incoming solver velocity, not the new
  velocity command that the controller has just assigned. Position tolerance,
  reference velocity tolerance and completed reference time are also required.
- Release returns the manipulation state to FREE. Existing HOLD motor and all
  loose_metal_body.gd render interpolation remain unchanged.

Ownership audit
- FREE: unchanged IronPull/SteelPush -> AllomancyInteraction -> physical adapter.
- APPROACH: Hermite reference with actual entry COM/velocity, adaptive endpoint,
  motion-derived duration/runway; explicit next-reference velocity owns motion.
- HOLD: existing damped controller. Separate branch, never concurrent with the
  approach command. AllomancyController returns before ordinary force application
  for both controlled states. No force-strength blend survives in that path.
- CAPTURED PUSH: existing corrected controlled_launch_axis() is the sole aim
  source, using clamped capture pitch/yaw. Virtual origin = physical COM - axis.
  Snapshot precedes synchronous release/cleanup, then shared Steel evaluation
  and impulse application. No COM-to-fixed-origin direction is used.

  cancellation, preventing further ordinary Steel from that same held press.
- Cleanup retains damped legitimate momentum while removing controller output.
  Independent world momentum may affect total velocity; it is not silently wiped.
