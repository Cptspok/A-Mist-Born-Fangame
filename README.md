# A Mist Born Fangame

Godot 4 gameplay prototype for first-person locomotion, Steel/Iron Allomancy, combat, inventory/equipment, NPC dialogue, enemies, and focused traversal test areas.

Open `project.godot` and run the configured `systems/session/playtest_shell.tscn` main scene. Historical milestone reports are indexed in [docs/devlogs/README.md](docs/devlogs/README.md). Follow [CONTRIBUTING_DEVLOGS.md](docs/devlogs/CONTRIBUTING_DEVLOGS.md) for future milestone documentation.
=======
