# A Mist Born Fangame

Godot 4 gameplay prototype for first-person locomotion, Steel/Iron Allomancy, combat, inventory/equipment, NPC dialogue, enemies, and focused traversal test areas.

Open `project.godot` and run the configured `scenes/playtest_shell.tscn` main scene. Current technical and playtest notes are kept in the milestone Markdown files at the project root.
