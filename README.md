# A Mist Born Fangame

=======

# This is a fan game based on the first trilogy of 'The Mistborn saga' by Brian Sanderson
# This project will serve as a portfolio but is very important to me as well. The works of Brandon Sanderson are important to me and I wanted to give people a door to the Cosmere, I hope you enjoy you time in Luthadel.

Godot 4 gameplay prototype for first-person locomotion, Allomancy, combat, inventory/equipment, NPC and focused traversal test areas.

Current technical and playtest notes are kept in the milestone Markdown files at the project root.
=======
